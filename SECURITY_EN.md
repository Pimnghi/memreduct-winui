## Supported versions

| Version | Supported |
| --- | --- |
| Latest stable `1.1.x` | Yes |
| Older or development builds | No |

## Reporting a vulnerability

Please use GitHub's **Private Vulnerability Reporting** feature on the
repository's Security page and select **Report a vulnerability**.

Do not disclose suspected vulnerabilities in a public Issue, pull request,
Discussion, or social media post. Include the affected version and
architecture, reproduction steps, impact, and any proof of concept that can be
shared safely. Reports are reviewed on a best-effort basis; no fixed response
or remediation SLA is currently offered.
